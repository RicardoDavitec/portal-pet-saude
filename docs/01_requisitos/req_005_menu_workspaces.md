# REQ-005 — Menu e workspaces

## Descrição

O menu lateral contém: G1…G5, Configurações, Cadastros, Relatórios, Documentos públicos, Sobre. Itens sem permissão não aparecem (exceto Documentos/Sobre para autenticados sem vínculo).

## Critérios de aceite

- [ ] Cinco entradas de grupo; G2–G5 podem ser placeholder
- [ ] G1 abre workspace com FAQ/dashboard via adapter
- [ ] Sem vínculo: só Documentos e Sobre
