# RN-003 — Tutor ⊆ Participante

## Enunciado

O papel `tutor` é um participante com atribuições de tutoria. No domínio, `papel=tutor` implica `ehParticipante=true`. Não coexistir `tutor` e `participante` para o mesmo usuário no mesmo grupo.

## Fonte

Decisão Q5 do estudo (2026-11-17); competências de Tutor e Participantes no edital.

## Exceções

Nenhuma conhecida.
