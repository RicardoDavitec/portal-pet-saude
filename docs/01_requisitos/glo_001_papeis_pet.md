# Glossário — papéis

## Termos

| Termo ou sigla | Significado | Contexto de uso |
|---|---|---|
| gestor_pet | Responsável municipal/estadual; papel **exclusivo** no portal | Cadastros, config, todos os grupos |
| coordenador_grupo | Coordena um único grupo tutorial G1…G5 | Vínculos e monitoramento do grupo |
| tutor | Participante com atribuição de tutoria | Orientação; no G1 acessa FAQ e PII |
| preceptor | Orienta alunos no serviço/campo | Frequência e supervisão |
| orientador_servico | Media serviço de saúde e projeto | Acompanhamento de resultados |
| monitor | Aluno bolsista do plano de atividades | Execução sob supervisão |
| participante | Papel base sem atribuição extra | Entregas MS; leitura FAQ G1 |
| G1…G5 | ChatBot, DashboardServiços, Totem, Vacinas, Educação Permanente | Workspaces do portal |
| Adapter C | Portal consome API Nest do Dashboard G1 | Integração FAQ; Vercel espelho |
| SIG-PET InfoSD | Sistema federal do MS | Portal **não** o substitui |
| Tutor ⊆ Participante | `papel=tutor` implica deveres de participante | RN-003; sem duplicar vínculos |
