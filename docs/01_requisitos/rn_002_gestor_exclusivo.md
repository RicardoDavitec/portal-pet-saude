# RN-002 — Gestor exclusivo

## Enunciado

Quem possui o papel `gestor_pet` não mantém `VinculoGrupo` ativo. Ao promover alguém a gestor, o sistema encerra vínculos de grupo vigentes dessa pessoa.

## Fonte

Decisão Q2 do estudo (2026-11-17).

Nenhuma conhecida.
